# strand-covers

Group cover images for the Strand home screen (Genres, Actors, Collections, Studios, ...).

Originally hosted on i.postimg.cc by the UME Omni template author, as 1–3 MB PNGs
(131 MB total). Re-encoded here at the original resolution as WebP q90 (29 MB total)
so the Apple TV home screen does not have to download and decode ~130 MB while scrolling.

Served via jsDelivr:
`https://cdn.jsdelivr.net/gh/ZixTro/strand-covers@main/covers/<file>`

`mapping.json` maps each original postimg URL to its file in `covers/`.
